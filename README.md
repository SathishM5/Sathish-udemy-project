# Udemy Clone – HTML & CSS

## 📌 Project Description
This project is a front-end clone of the Udemy website, developed using HTML5 and CSS3. The main objective of this project is to recreate the look and feel of Udemy's online learning platform with a clean, user-friendly, and responsive design.

It includes a homepage layout showcasing online courses, categories, navigation menus, search functionality UI, and course cards.

## 🚀 Technologies Used
- HTML5
- CSS3

## ✨ Features
- Clean and user-friendly interface
- Navigation bar
- Course search bar UI
- Course categories section
- Popular courses display
- Course cards with images and details
- Footer section

## 🎯 Project Objective
The purpose of this project is to improve my front-end development skills and gain practical experience in building website layouts using HTML and CSS.
